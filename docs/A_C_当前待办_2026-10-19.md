### 3. 输入怎么拼

Prompt 与 packet 一一对应，拼法是：

```python
from pathlib import Path

sample, version, kind, packet = "S007", "V0", "SQLi", "S007_v1"
prompt = Path(f"prompts/{kind}_{version}.txt").read_text(encoding="utf-8")
code = Path(f"dataset/packets/{packet}/code_input.txt").read_text(encoding="utf-8")
run = f"F_{sample}_{version}_R1"
Path(f"runs/{run}").mkdir(parents=True, exist_ok=True)
Path(f"runs/{run}/input.txt").write_text(prompt.rstrip() + "\n\n" + code, encoding="utf-8", newline="\n")
```

### 4. 每条保存什么

```text
runs/<run_id>/
  input.txt
  raw_output.txt          # 模型完整原文，代码围栏保留
  normalized.json         # 解析后的 JSON + format_valid
  metadata.json           # 哈希、模型、设置、时间
  screenshot_settings.png # 模型名/深度思考/搜索状态
  screenshot_answer_1.png
  screenshot_answer_2.png
```

JSON 坏了：raw 不动，在 normalized 里人工转录并标 `format_valid=false`。

### 5. POC

- 模型给了 POC：先存 `pocs/<run_id>/original.py`，**先读后跑**；
- 只允许 `127.0.0.1:4280`；外发、删文件、读 Cookie 的不执行；
- 只改地址/路径存 `adapted.py` 并留 diff；改请求/断言存 `logic_fixed.py`；
- `verification=triggered` 必须有实际观察证据，HTTP 200 不算；
- 没给 POC：`poc_generated=false`，`verification=not_run`，不要自己补。

### 6. 回填与提交

只改 `runs/formal.json` 自己 9 条的：

`prediction`、`location_correct`、`poc_generated`、`raw_execution_ok`、`environment_execution_ok`、`logic_changed`、`verification`、`error_reason`、`evidence_paths`。

- `status` 保持 `executed_pending_review`，**不要自己改 reviewed**；
- `reviewer` 保持计划值；
- 提交后开 PR 到 `a/criteria-and-sql01`，@ 对应复核人。
