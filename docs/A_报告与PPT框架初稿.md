## 二、A 负责章节的方法论初稿

### 2.1 判定标准（对应第 3/4 章）

- 判定标准依据 `docs/judgment_criteria.md`：SQLi 四项检查、XSS 五项检查。
- 每条结论只取「满足 / 不满足 / 未知」，并附源码行号与运行证据。
- 真值来自「代码分析 + 参考验证」，不来自被评估模型回答。

### 2.2 指标口径（对应第 4/6 章）

- 依据 `docs/metrics_protocol.md`：prediction 三值（vulnerable/safe/uncertain）、
  TP/FP/TN/FN/U_positive/U_negative。
- 指标：精确率、保守召回率（分母含待判定阳性）、误报率（分母含待判定阴性）、
  全样本判对比例、待判定率。
- 定位正确与预测正确分开；POC 可执行（raw/environment/logic_changed）与漏洞触发（triggered）分开。

### 2.3 评估与误漏报归因（对应第 5/6 章）

- 归因表字段：现象—证据—主要原因—修正措施—是否复测。
- 主要原因七选一（必要时加次要原因）：缺上下文 / 判定规则不适配 / 模型编造位置 /
  会话或环境错误 / POC 逻辑错误 / 浏览器状态干扰 / 真值争议。
- 人工复筛后的「确认数/保留率」与 LLM 原始准确率分开报告。

## 三、PPT 大纲（约 10 页）
