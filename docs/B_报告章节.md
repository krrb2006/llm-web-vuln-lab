# B 报告章节草稿：传统分析与 LLM 辅助、模块 2 Prompt 工程

## 传统漏洞分析与 LLM 辅助方式

传统代码审计沿入口、数据传播、处理、危险操作和运行效果建立可复核链条。SQLi 需区分用户输入作为绑定值与影响查询语法的拼接；XSS 需结合最终浏览器上下文判断编码、净化和执行。参考验证要从普通业务请求出发，比较受控测试请求；安全结论还要确认防护覆盖目标路径，而非仅凭测试失败。

LLM 可快速提示候选入口、跨函数关联、可能缺失的上下文和验证步骤。其输出是待核查的分析材料，不能代替源码与运行证据。模型可能从函数名猜测行为、编造行号、把 HTTP 200 当作触发，或忽略浏览器执行条件。因而本实验将预测、定位、证据质量、POC 生成、脚本执行和漏洞触发分开记录。人工复核逐项映射 Fxx 行号到原始源码，检查环境、原始 POC、改动 diff 和实际现象。

|环节|传统人工分析|LLM 辅助分析|最终核验|
|---|---|---|---|
|路径发现|逐层查入口、调用链与 sink|提出候选路径|源码和真实调用条件|
|防护判断|按 SQL/浏览器上下文审查|描述可能有效的过滤|检查实现、位置与覆盖范围|
|验证|构造普通/测试对照|生成候选 POC|人工审阅后在本地靶场运行|
|结论|结合参考验证与复核|输出 vulnerable/safe/uncertain|原文、证据、真值和跨人审核|

## 模块 2：Prompt 工程

六份 Prompt 对 SQLi、XSS 各设 V0/V1/V2，统一四段：安全审计角色、核心任务、类型专属规则、JSON 与 POC 契约。各版本维持同一目标、输入规范与十个最低字段。V0 是可用基线，已要求行号、证据、本地 POC 和不可信代码边界。V1 候选增加可达的数据流、有效防护、缺失上下文与原始行号的具体证据。V2 候选重述 V1 证据约束，增加普通/测试对照、触发观察、运行前提和注释指令不可信的强调；不把已有边界约束说成 V2 首创。

|约束|V0|V1 候选|V2 候选|
|---|---|---|---|
|安全审计、专属规则与统一 JSON|有|保持|保持|
|不可信代码及注释边界|有|保持|强调注释干扰|
|可达 source→sink、具体防护与缺失上下文|基本要求|逐项强化|完整重述|
|POC 运行前提、普通/测试对照与触发断言|基本要求|保持|逐项强化|
|独立被测模型原文|12/12|12/12|12/12|

三轮开发回答现已全部归档，每轮 12 条，逐样本 code_input 哈希固定。V0→V1 根据 S002/S004 的执行点证据、S017/S018 的跨请求证据问题改句，V1 中 S004 新增实际 execute 行、S017/S018 进一步明确独立读取阶段。V1→V2 根据原始 POC 的字符串断言、目标与跳转限制、存储状态等问题补充验证要求。两轮记录见 `results/B_SQLi_iteration.md`、`results/B_XSS_iteration.md` 和对应比较报告。2026-10-20 重算 36 条开发原文、输入与当前 Prompt 哈希及严格 JSON 均通过；所有开发模型 POC 均未执行，不得将更具体的代码和说明写成已验证的可靠性提升。

按 A 集成后的正式统计 `results/formal_eval_2026-10-19-v2/summary.md`，每版 12 个测试样本均为 TP=6、TN=6、FP=0、FN=0，V0→V1→V2 没有标签纠错或新增退化。这是受控小样本的观测，不能外推通用准确率。全组模型 POC 仅两条有实际触发记录，其余 34 条为 not_run；B 本人九条全部 not_run，不能把全组某例成功归到 B 的 POC。V2 的 S004 locations 仍可能遗漏实际 execute 行，说明增加验证约束不保证证据覆盖单调改善。

## 模块 5：缺陷与优化贡献

本研究受限于 24 个配对教学样本、可能的训练语料重合、模型界面版本漂移和缺失会话截图。四个开发样本的固定注释句式共 16 条 INJ 原文已归档，8 对 Original/Injected 预测均未改变，不能宣称 V2 比 V0 更抗注入或模型完全安全。B 独立核对输入仅追加合法注释，关键输入/输出证据保留；注入版语法和业务参考等价验证尚无新增运行证据。该批次不替代 A 后续另行规划的四类攻击矩阵，见 `results/B_injection.md`。

独立复核 C 的九条还发现：S009 V2 的 SQL 注释尾空格被源码 trim 删除，原 POC 可能失败；S023 V1/V2 普通对照导航到 example.org，违反仅本地验证约束。两者不能因模型标签正确而忽略。另发现 CRLF 原文导致严格解析器漏认 JSON 围栏，已修复解析视图并验证不改原文字节；这属于工具错误，不算模型格式错误。
