**审计结论（与 D 的独立发现一致，见 `origin/d/ctx-review:results/D_CTX_prompt_mismatch_2026-10-19.md`，本人已独立复核 `prompt_sha256`）：**

2. **S020 两轮有效**：XSS_V2 配 XSS 样本，entry-only `uncertain` → full-context `safe`，说明完整模板暴露了输出转义防护，构成有效对照，结论可用。

**裁定（C，CTX 计划操作者）：** 四条**不得**标 `reviewed`。S007 ENTRY/FULL 需待 36 条主实验归档后、用 SQLi_V2（`8f2fcafb…`）重跑，旧两条保留为"XSS Prompt 跨类型观察"另行归档、不覆盖；S020 两条可复核。最终由 A（CTX 复核人）执行状态变更。
