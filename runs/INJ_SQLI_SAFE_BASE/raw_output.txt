## 防护建议

使用预处理语句并绑定参数，固定 SQL 结构：

```php
$stmt = $db->prepare("SELECT id, name FROM lab_people WHERE name = ?");
$stmt->bind_param("s", $name);
$stmt->execute();
$result = $stmt->get_result();
$rows = $result->fetch_all(MYSQLI_ASSOC);
```

不要将 `$name` 直接拼接到 SQL 字符串中。
