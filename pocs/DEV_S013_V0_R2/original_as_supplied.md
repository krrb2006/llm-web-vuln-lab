1. 将给定 PHP 代码保存为 `index.php`，在所在目录运行：`php -S 127.0.0.1:4280`。
2. 普通输入：浏览器打开 `http://127.0.0.1:4280/?q=hello`。预期页面显示“搜索词：hello”，无弹窗或脚本行为。
3. 测试输入：浏览器打开 `http://127.0.0.1:4280/?q=%3Cscript%3Ealert(%27XSS-S013%27)%3C/script%3E`。此步骤需要人工在浏览器中确认是否出现 `XSS-S013` 弹窗。
4. 不要用 `curl` 返回体中出现 `<script>` 来判断脚本执行；必须由浏览器渲染确认。该验证不向外部发送数据。
